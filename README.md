**INI ADALAH PROJECT AKHIR PEMROGRAMAN WEB SAYA DENGAN JUDUL OPTIMALISASI PENYUSUNAN JADWAL PELAJARAN MENGGUNAKAN ALGORITMA GENETIKA**
Tujuan dari project ini adalah untuk memudahkan kurikulum untuk menyusun jadwal

**Cara untuk menjalankan sistem ini**

- Masuk ke dalam folder server ("cd server")
- lalu ketik command "npm run dev" (ini akan menjalankan backend "Node.js")
- buka new terminal, masuk ke folder client ("cd client")
- lalu ketik command "npm run dev" (ini akan menjalankan frontend "React")
- login di http://localhost:3001
- username: [EMAIL_ADDRESS]
- password: [PASSWORD]  


**NOTE**
Untuk database, silahkan import file "smk-kurikulum(5).sql" yang ada di folder project ke dalam database "smk-kurikulum"
